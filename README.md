# Vulnerability Assessment Report - hexacoreclasses.in

## 🔍 Overview
This repository contains a professional Vulnerability Assessment Report (VAR) for the live website **hexacoreclasses.in**. The assessment was conducted following a strictly read-only and passive reconnaissance methodology to identify potential security misconfigurations and exposure risks.

## 🛡️ Assessment Details
- **Target URL:** [hexacoreclasses.in](https://hexacoreclasses.in)
- **Scope:** Web Application (External)
- **Methodology:** Passive Reconnaissance & Automated Triage (OWASP/PTES)
- **Date:** 22/04/2026
- **Status:** Completed

## 🛠️ Tools Used
- **Nmap 7.98:** Network port and service version enumeration.
- **OWASP ZAP 2.17.0:** Passive vulnerability scanning and alert triage.
- **Browser DevTools:** Manual inspection of HTTP response headers and security configurations.

## 📊 Summary of Findings
- **Critical / High:** 0
- **Medium:** 3 (Clickjacking, Missing CSP, Missing Security Headers)
- **Low:** 1 (Port 8080 Service Disclosure)
